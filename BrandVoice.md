# Brand Voice Manual - Jardel Messias

## 1. Diretriz Principal (Princípio da Plataforma)
Este projeto não deve ser tratado como um "portfólio de desenvolvedor". É a plataforma oficial de uma marca profissional especializada em criar soluções digitais com software, inteligência artificial e automação. O objetivo principal da nossa comunicação é converter visitantes em clientes qualificados, mostrando clareza, confiança e autoridade de negócios, sem excesso de termos técnicos arrogantes.

---

## 2. Personalidade da Comunicação

* **Clara:** Vá direto ao ponto. Use frases curtas. O cliente precisa entender o valor imediatamente.
  * *Antes (Ruim):* "Desenvolvimento Full Stack utilizando arquitetura escalável baseada em microsserviços."
  * *Depois (Bom):* "Desenvolvo sistemas modernos preparados para crescer junto com sua empresa."
* **Segura:** Transmita convicção nas soluções propostas. Evite termos que expressem dúvida.
  * *Inseguro:* "Acho que...", "Talvez possamos tentar...", "Vou pesquisar para ver se dá..."
  * *Seguro:* "A melhor solução para esse cenário é...", "Podemos resolver isso através de..."
* **Humana:** Trate a conversa com o cliente como uma parceria estratégica. Fale de negócio antes de falar de código.
* **Técnica quando necessário:** Só descreva frameworks e bancos de dados se for questionado diretamente ou para validar competência após apresentar os benefícios do projeto.
* **Objetiva:** Cada bloco de texto no site deve cumprir uma função direta do funil de conversão.

---

## 3. Estrutura Padrão para Apresentação de Projetos
Todos os projetos e estudos de caso devem ser descritos seguindo exatamente a ordem abaixo:
1. **Contexto:** De onde surgiu a ideia ou a oportunidade do projeto.
2. **Problema:** Qual gargalo de negócio existia (WhatsApp lento, planilhas confusas, agendamentos duplicados).
3. **Solução:** O que foi construído para sanar o problema.
4. **Benefício / Resultado:** Qual melhoria prática foi gerada (ex: economia de horas, aumento de conversão, redução de erros).
5. **Tecnologia:** Quais ferramentas deram vida à solução.

## 4. Elevator Pitch (Discursos Oficiais)

### O Discurso de 10 Segundos (Para apresentações rápidas)
> "Desenvolvo sistemas inteligentes que ajudam empresas a automatizar processos e crescer utilizando tecnologia."

### O Discurso de 30 Segundos (Elevator Pitch Completo)
> "Sou Software Engineer especializado em IA e automação. Desenvolvo sistemas, aplicativos e soluções sob medida para empresas que desejam organizar processos, automatizar tarefas e crescer utilizando tecnologia. Meu objetivo é transformar problemas reais em soluções simples, eficientes e preparadas para evoluir junto com o negócio."

## 5. Respostas Estratégicas para o Consultor Digital

### Quando perguntado: "O que você faz?"
> "Desenvolvo soluções de software para empresas, utilizando inteligência artificial, automação e sistemas sob medida para resolver problemas reais do negócio."
