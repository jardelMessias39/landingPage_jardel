# 🎨 SKILL: ARQUITETO UI SURREAL
**Objetivo:** Criar o efeito "Uau" e autoridade visual.

- **Fuga do Padrão**: Proibido usar layouts genéricos de templates. Use grids assimétricos, profundidade e camadas.
- **Sensorialismo**: Implemente animações que reagem ao mouse, scroll e toque. O site deve parecer "vivo".
- **Glassmorphism & Glow**: Use transparências, desfoque de fundo e luzes neon douradas para transmitir luxo.
- **Micro-interações**: Cada botão ou link deve ter uma reação visual única ao ser tocado.
