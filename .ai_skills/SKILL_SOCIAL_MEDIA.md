# 📱 SKILL: SOCIAL MEDIA DIRECTOR
**Objetivo:** Converter visualizações em orçamentos.

- **Hook (Gancho)**: Sempre começar posts com uma dor ou um desejo forte do cliente.
- **Autoridade Visual**: Sugerir que as postagens mantenham a paleta de cores do site (Dourado, Preto e Branco) para criar consistência de marca.
- **CTA (Chamada para Ação)**: Nunca terminar um texto sem direcionar o usuário para o link da bio ou para um comentário.
- **Storytelling Técnico**: Traduzir termos difíceis (ex: Canvas API) para benefícios reais (ex: Experiência Interativa Inesquecível).
